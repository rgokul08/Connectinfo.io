# Connectinfo.com

> **Connect. Organize. Communicate.**

Connectinfo.com is a modern contact management platform built with **React and Tailwind CSS**, designed to make storing, organizing, and connecting with people simple and efficient.

### ✦ Highlights

* 🔐 Simple **Login & Create Account** with LocalStorage
* 👤 Add, edit, delete, archive & organize contacts
* ⭐ Favorites, groups & custom tags
* 🔎 Smart search, filtering & sorting
* 📧 Direct email via `mailto:` + **EmailJS**
* 📞 One-click calling via `tel:`
* 📤 Import & export contacts
* 📱 Contact sharing & QR code
* 🕒 Activity timeline
* ⌨️ Command palette & keyboard shortcuts
* 🌙 Light / Dark mode
* 🧊 Subtle 3D interactions
* 📱 Fully responsive & accessible UI

### 🛠️ Tech Stack

**React · Vite · JavaScript · JSX · Tailwind CSS · React Router · EmailJS · LocalStorage**

### 🎨 Design

Built around the **Coral · Gold · Teal · Blue** palette from [Color Hunt](https://colorhunt.co/palette/ff7f50ffd16606d6a0118ab2?utm_source=chatgpt.com) with a clean, premium SaaS-inspired interface.

### ✧ Project Vision

Connectinfo.com combines **contact management, communication, and lightweight CRM functionality** into one simple, intuitive experience.

**Manage contacts. Build connections. Communicate faster.**
